# 🖼️ Criar Imagens Placeholder

## Imagens Necessárias

### 1. Logo ASM (logo-asm.webp)

- Dimensões: 250x200px
- Formato: WebP
- Conteúdo: Logo da ASM Marketing Digital

### 2. Background Hero (hero-bg.webp)

- Dimensões: 1920x1080px
- Formato: WebP
- Conteúdo: Background sutil para o hero

### 3. Foto Anelita (hero-person.webp)

- Dimensões: 400x400px
- Formato: WebP
- Conteúdo: Foto profissional da Anelita

### 4. Foto Bio (photo-bio.webp)

- Dimensões: 400x400px
- Formato: WebP
- Conteúdo: Foto de rosto da Anelita

### 5. Instagram Logo (instagram-logo.png)

- Dimensões: 30x30px
- Formato: PNG
- Conteúdo: Logo do Instagram

### 6. OG Image (og-image.png)

- Dimensões: 1200x630px
- Formato: PNG
- Conteúdo: Imagem para compartilhamento social

### 7. Favicon (favicon.ico)

- Dimensões: 32x32px
- Formato: ICO
- Conteúdo: Ícone do site

## Ferramentas para Criar Placeholders

### Online:

- placeholder.com
- picsum.photos
- unsplash.com

### Comando para criar placeholders:

```bash
# Criar pasta public se não existir
mkdir -p public

# Baixar placeholders (exemplo)
curl "https://picsum.photos/250/200" -o public/logo-asm.webp
curl "https://picsum.photos/1920/1080" -o public/hero-bg.webp
curl "https://picsum.photos/400/400" -o public/hero-person.webp
curl "https://picsum.photos/400/400" -o public/photo-bio.webp
```
